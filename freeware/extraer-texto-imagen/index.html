Extraer texto de una imagen (OCR) gratis

Convierte una foto, captura de pantalla o documento escaneado en texto editable con reconocimiento óptico de caracteres (OCR). Sube la imagen, elige el idioma y copia el texto. El reconocimiento ocurre en tu navegador: tu imagen no se sube a ningún servidor (solo se descarga una vez el modelo de idioma).

¿Cómo extraer el texto de una imagen?

  • Sube o arrastra la imagen (JPG, PNG, etc.).
  • Elige el idioma del texto (español, inglés o ambos).
  • Pulsa Extraer texto y copia o descarga el resultado.

Consejos para mejores resultados

Usa imágenes nítidas, con buena iluminación y el texto lo más recto posible. El OCR funciona mejor con texto impreso que manuscrito.
