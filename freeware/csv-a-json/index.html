Convertir CSV o Excel a JSON y SQL

Pega datos desde Excel o un archivo CSV y conviértelos al instante a JSON (arreglo de objetos) o a sentencias SQL INSERT listas para tu base de datos. Detecta el separador automáticamente, respeta los encabezados y todo ocurre en tu navegador: tus datos nunca se suben.

¿Cómo se usa?

  • Pega el CSV (o cópialo directo desde Excel/Sheets) o sube el archivo.
  • Indica si la primera fila son encabezados y el separador.
  • Elige JSON o SQL y copia o descarga el resultado.

¿Para quién es?

Para desarrolladores, analistas y estudiantes que necesitan mover datos de una hoja de cálculo a una API, una base de datos o un archivo de configuración, sin herramientas pesadas ni anuncios.
