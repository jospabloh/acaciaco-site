Política de privacidad

Lineamientos generales sobre recopilación, uso y resguardo de información

Esta política se presenta en lenguaje claro para mejorar comprensión y confianza, sin pretender sustituir acuerdos contractuales, anexos o condiciones específicas que puedan aplicar en determinados servicios.

1. Alcance

Esta política aplica, de manera general, al uso del sitio web de ACACIA, sus aplicaciones, formularios de contacto, canales de soporte, procesos de consultoría y servicios digitales relacionados.

2. Información que puede recopilarse

Dependiendo de la solución o interacción, puede recopilarse información como nombre, correo electrónico, teléfono, datos de cuenta, identificadores de usuario, información operativa, información de negocio y datos técnicos necesarios para funcionamiento, soporte o mejora del servicio.

  • Datos de contacto: para atender solicitudes, soporte o seguimiento comercial.
  • Datos de cuenta: para autenticar acceso, administrar perfiles y controlar permisos.
  • Datos operativos: para habilitar funciones, reportes y procesos del servicio contratado.
  • Datos técnicos: para seguridad, diagnóstico, estabilidad y mejora continua.

3. Finalidades de uso

La información puede utilizarse para:

  • Operar aplicaciones y servicios contratados o solicitados.
  • Dar soporte, seguimiento y atención a usuarios o clientes.
  • Prevenir abuso, fraude, uso indebido o incidentes de seguridad.
  • Mejorar experiencia, estabilidad, calidad y funcionalidad.
  • Atender contacto comercial, implementación o acompañamiento técnico.

4. Compartición con terceros

En ciertos casos pueden intervenir proveedores o plataformas de terceros para autenticación, hosting, analítica, mensajería, pagos, correo o infraestructura tecnológica. Cuando esto ocurra, dichos terceros pueden procesar información bajo sus propias condiciones y políticas.

ACACIA no vende datos personales como modelo comercial.

5. Conservación y seguridad

La información se conserva por el tiempo razonablemente necesario para operar el servicio, atender obligaciones contractuales, dar soporte o cumplir finalidades legítimas relacionadas con la operación.

También se aplican medidas razonables de seguridad, control de acceso y buenas prácticas técnicas para reducir riesgos de uso no autorizado, alteración, pérdida o exposición indebida.

6. Derechos y solicitudes

Cuando corresponda, pueden solicitarse aclaraciones sobre uso de información, correcciones, actualizaciones o revisión del tratamiento aplicable al caso concreto, sujeto al tipo de servicio, relación vigente y marco correspondiente.

7. Contacto

Para dudas sobre privacidad, datos, seguridad o tratamiento de información, se puede contactar a ACACIA por:

  • Correo: contacto@acaciaco.com.mx
  • WhatsApp: +52 449 895 8291
